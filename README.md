# 🐍 Snake Game

A fun and interactive Snake game built with pure HTML, CSS, and JavaScript!

## Features

✨ **Classic Snake Gameplay**
- Move the snake using Arrow Keys or WASD
- Eat food to grow and score points
- Avoid walls and colliding with yourself

🎮 **Game Controls**
- **Arrow Keys** or **WASD** - Move the snake
- **Start Game** - Begin playing
- **Pause** - Pause/Resume the game
- **Reset** - Restart the game

📊 **Score System**
- Each food eaten = +10 points
- High score is saved locally in your browser
- New high score alert when you beat your personal best

🎨 **Features**
- Beautiful gradient UI
- Smooth animations
- Responsive design (works on mobile)
- Glowing effects for better visibility
- Grid background for better gameplay

## How to Play

1. Click **"Start Game"** to begin
2. Use **Arrow Keys** or **WASD** to move the snake
3. Eat the red dots (food) to grow and score points
4. Avoid hitting the walls and yourself
5. Try to beat your high score!

## Installation

Simply open `index.html` in your web browser and start playing!

```bash
git clone https://github.com/karanmourya3838-maker/Karan-Mourya.git
cd Karan-Mourya

```

## Game Rules

- The snake starts in the middle of the board
- Each food eaten increases your score by 10 points
- The game ends when you hit a wall or collide with yourself
- Your high score is automatically saved
